# CCAF — My Trap Log

Exam-agnostic catalogue of the **trap *types*** that catch me, by axis of failure.
Specific questions differ across exams; these patterns transfer. Add one row per mistake.

## The 5 axes
1. **Determinism** — influences vs guarantees (prompt/CLAUDE.md/.claude/rules/description vs hook/schema/forced-specific-tool).
2. **Exact hit** — similar vs exactly the thing (`tool_choice: any` vs forced; Grep=contents vs Glob=paths).
3. **Right diagnosis** — solves the wrong problem (plan mode when the gap is requirements; summary when full context is needed).
4. **Proportionality** — too much / too little (over-delegation; review everything or by confidence).
5. **Root-cause / antipattern** — symptom not cause (bigger model/window; stronger prompt; self-reported confidence; sentiment).
